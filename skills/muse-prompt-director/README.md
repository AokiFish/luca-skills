# Muse Prompt Director Skill

A reusable skill for turning a short idea into a coherent, timed, continuity-aware AI video prompt.

## Install
Place the `muse-prompt-director` folder in the skills directory supported by your agent platform. The main entry point is `SKILL.md`.

## Use
Give the skill a simple theme or story idea, for example:
- “A young woman finds a mysterious key in an old train station.”
- “Make a funny 15-second video about a cat stealing a chef's hat.”
- “Create a cinematic product reveal for a glass perfume bottle.”

Mention the target platform, duration, aspect ratio, language, and character limit when they matter. The skill will make reasonable creative choices for missing details.
