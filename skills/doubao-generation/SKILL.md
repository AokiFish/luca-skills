# doubao-generation

视频走豆包网页，不走 Muse 视频接口。Muse 的 media.generate_video 返回 403 video_not_available（调用账号所在地区不可用，长期限制，不得重试/绕行）；关键帧预览不是真视频。

## 视频生成（2026-11-13 实测通过）

1. doubao.com 须登录；未登录打开会跳区域限制页。
2. 入口：首页输入框旁「更多技能 → 快捷功能 → 视频生成」。模型 Seedance 2.0 Mini（默认）/ 2.0 / 2.0 Fast / 2.5 / 2.5 Flash；时长 4–15 秒；比例 3:4/4:3/9:16/16:9/1:1/21:9；实测 5 秒、720p、16:9 约 3 分钟出片。
3. 图生视频：普通对话模式先用「+ → 上传文件或图片」把图附到输入框，再切到「视频生成」模式，图会保留作首帧。每次生成耗一次每日免费额度（次数未公布）。
4. 验收：核验是真向前推进的视频，不是静止图。

## 图生图（2026-11-15 实测通过）

1. 入口：聊天页底部点「图像生成」→ 输入框左下角「+」上传参考图 → 输入描述。模型 Seedream 5.5/5.0 Pro/5.0 Flash（默认）/4.5/4.0。
2. 图像生成模式下点「+」未弹出可见菜单时，用对话模式的「+ → 上传文件或图片」作备选入口。
3. 同一身份换装已验证成立（Seedream 5.0 Flash：同一人、服装全对）。

## 验收

- 视频是真 MP4、连续动作；图生图同一身份、服装全对；入口与模型名与实测一致。
