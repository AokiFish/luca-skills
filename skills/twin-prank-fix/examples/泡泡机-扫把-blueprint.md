# 双胞胎蓝图 · 泡泡机 vs 小扫把（示例 · 对称反功能）

> `twin-prank-fix` Skill 的**第二个范例**，演示「对称反功能」道具分支（一个制造、一个收拾），证明视觉语法可迁移。直接可用，长相由参考图锁定。

## 道具工坊输出（四步法）

1. 原版标尺：拐杖 = 身份(绅士) + 触及(勾远处) + 无意(自己碰到的)。
2. 双胞胎道具：恶作剧T 背**手持泡泡机**，善后T 拿**小扫把+粘毛器**，成对。
3. 温差测试：同是泡泡，一个当「艺术创作」，一个当「灾难现场」——温差成立。
4. 反转点：泡泡看着浪漫无害，却是隐性麻烦（糊镜/引撞）；扫把看着平淡，却是真正拯救。

## 道具卡

- **恶作剧T 道具**：手持泡泡机。身份信号 = 梦幻/捣蛋顽童；触及 = 喷泡泡覆盖远处、糊视线、引小孩追撞；无意面具 = 「我只是背着玩，泡泡自己飘过去的」。
- **善后T 道具**：小扫把 + 粘毛器。身份信号 = 清洁/收拾的人；触及 = 扫水渍、扶被绊者、滚掉衣物泡泡；无意面具 = 「路过顺手擦一下」。
- **成组方式**：对称反功能（制造 vs 收拾，视觉成对）。
- **反转点**：浪漫与务实的反转——泡泡是隐性麻烦，扫把是真正拯救。

## 人设卡

- **恶作剧T**：天真导演型。哼歌、自言自语「看这多美」，坏事发生后无辜环顾。职能 = 抛出荒诞。
- **善后T**：无奈共犯型。零台词、叹气、翻白眼、手上精准。职能 = 接住并恢复秩序。
- **温差方向**：一个在「创作」，一个在「灭火」。

## 视觉语法命中清单

- [x] G1 泡泡机+小扫把一眼成组，身份反差明显
- [x] G2 喷泡泡/扫泡泡都「无意」（自己飘的/路过擦的）
- [x] G3 事件全在随手半径，两人同半径同口气
- [x] G4 善后T 零台词靠叹气/翻白眼/瞪，恶作剧T 哼歌/自语
- [x] G5 每拍温差：欣赏 vs 补救、助兴 vs 扣停
- [x] G6 修补在恶作剧同一口气内落地（镜5 糊脸仍修）

## 风险 / 下版迭代

1. 泡泡为半透明动态，模型易把「糊镜/糊屏」渲染成「透明无水渍」——提示词强调 `visible wet bubble film on lens/screen`。
2. 两双胞胎长相靠参考图锁定一致性，加 `no extra limbs, consistent twin appearance` 防护。
3. 镜5 长镜连锁动作多，建议拆成 2–3 个生成单元，用结尾定格锚点衔接。
4. 若想更「哪吒」，把恶作剧T 的自语换成更嚣张的碎碎念（仍不出完整台词）。
