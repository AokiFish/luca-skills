# 分镜蓝图模板（Blueprint Template）

本模板产出一份「双胞胎恶作剧 + 善后」短视频的节拍分镜蓝图，可直接喂给视频模型或接力 `video-link-to-prompt` 的拆解流程。人物一律用占位符，不含具体长相。

## 46s 结构骨架（默认；时长可改，节拍密度随之调整）

- **0–3s 钩子**：同框亮出双胞胎 + 道具 + 第一个「恶作剧 → 善后」一气呵成。必须在前 3 秒让观众看懂「这组关系」。
- **3–15s 三连拍**：三个递进的恶作剧 → 善后微节拍（每 3–5 秒一翻）。
- **15–30s 双杀**：一个恶作剧引发连锁，善后 twin 被创意困住，但手仍在修。
- **30–40s 温差爆点**：两人对同一件事露出完全不同的理解（核心笑点，全片最高光）。
- **40–46s 收尾 tag**：道具最后的「无意之举」呼应开头，闭环。

## 每镜 schema（与 video-link-to-prompt 兼容）

| 字段 | 说明 | 取值示例 |
|---|---|---|
| 时间区间 | 起止秒数 | `0–3s` |
| 景别 | 画面范围 | 大远景 / 远景 / 全景 / 中景 / 中近景 / 近景 / 特写 / 大特写 |
| 机位 | 拍摄角度 | 平视 / 仰拍 / 俯拍 |
| 运动 | 摄像机运动 | 固定 / 推 / 拉 / 摇 / 移 / 跟 / 手持 |
| 动作节拍 | 有序可见动作 ①②③，每拍有起承转合；禁止脑补 | `①A ②B ③C` |
| 声音 | 非语言音节 / 环境音 / 音乐提示（无声视频也要标） | `哼歌/啧/风声/鼓点` |
| 段色调 | 本段统一色彩关键词 | `暖橙街道` / `冷蓝傍晚` |
| 结尾定格 | 本镜最后一帧，作为下一镜首帧（零跳变） | 描述末帧构图 |

## 角色占位符约定（关键）

- 用 `[恶作剧T]` / `[善后T]` 占位，**只写动作与表情，绝不写长相**。
- 长相交给参考图（由 `image-reference-to-prompt` 类流程锁定）负责。
- 蓝图顶部放「道具卡」（见 prop-logic-workshop 输出物）与「人设卡」（见 twin-personas）。

## 统一风格句（anti-drift）

- 组一句固定风格句，CN + EN 各一版，**逐镜原文粘贴，不改写、不缩写**（风格漂移主要来自这句被逐镜改写）。
- 例：`实拍质感，自然光，浅景深，9:16 竖屏，全片统一渲染风格` / `Cinematic real-footage look, natural light, shallow depth of field, 9:16 vertical, consistent style throughout`。

## 每镜提示词配方

**风格句 + 景别/机位 + 运动 + `[剧情：…]`（动作节拍） + 结尾定格锚点**。

- 角色只描述动作表情，用占位符。
- 易变形的镜头加一句通用防护（如 `no extra limbs, consistent with unified style`）。
- 固定规则（风格句、占位符、段色调逻辑、画幅、结尾定格衔接）与可替换变量（`[剧情：…]` 文本、设定、道具）分开。

## 输出文件命名

`twins-blueprint-<slug>.md`，slug 取概念名（如 `twins-blueprint-对称拐杖反转.md`）。不用裸名 `blueprint.md`。

## 默认输出结构

1. 道具卡 + 人设卡（概念锚点）
2. 统一风格句（CN + EN 原文）
3. 46s 结构骨架（节拍总览）
4. 逐镜拆解（用上面 schema：景别/机位/运动/动作节拍①②③/声音/段色调/结尾定格 + CN+EN 提示词）
5. 视觉语法命中清单（G1–G6 逐条勾）
6. 2–4 条风险 / 下版迭代点
