# 字幕规范（SRT / VTT 通用）

## 一、何时生成字幕

- 视频画面**无内嵌文字**（用户要求无字幕/无水印）→ 生成外挂字幕文件，随内容包交付。
- 视频画面**已有内嵌字幕** → 不再生成外挂字幕（避免叠加），内容包 `subtitles` 字段留空。

## 二、SRT 格式

```srt
1
00:00:00,000 --> 00:00:03,000
{第一句台词}

2
00:00:03,000 --> 00:00:07,000
{第二句台词}
```

规则：序号递增、空行分隔、时间码用**逗号**毫秒（`HH:MM:SS,mmm`）、UTF-8 编码。

## 三、VTT 格式（YouTube 原生）

```vtt
WEBVTT

00:00:00.000 --> 00:00:03.000
{第一句台词}
```

规则：首行必须 `WEBVTT`、时间码用**点号**毫秒（`HH:MM:SS.mmm`）、可省略序号。

## 四、时间轴对齐

1. 有分镜表：每句起点对齐镜头起始，终点对齐镜头结束或下句起点。
2. 最后一条字幕终点 = 视频结束时间（如 15s 视频到 `00:00:15,000`）。
3. 每句 2-5 秒；<1s 读不完，>6s 拖节奏，超长拆句。
4. 无分镜时按剧情自然分段，交付注明"时间轴为估算，可微调"。
5. 双语版本的两套字幕**时间轴逐条完全一致**，只替换文本，保证条数、序号、起止时间一一对应。

## 五、断句原则

- 短句 + 口语化，一层意思一句。
- 保留语气词（卡顿、破功、感叹），与配音情绪一致。
- 标点跟随情绪：疑惑 `?`、破功 `!`、未完 `...`。
- 语音语言跟随配音；字幕语言按平台选用（见第七节），默认出中英两套。

## 六、交付

每次交付一套字幕提供 `<视频名>.srt` 与 `<视频名>.vtt`，内容一致，仅格式差异。双语版本命名：

- 中文：`subtitles.zh.srt` / `subtitles.zh.vtt`
- 英文：`subtitles.en.srt` / `subtitles.en.vtt`

## 七、双语字幕与平台选择

### 1. 两套字幕的来源关系

- 以**视频实际配音语言**为准生成主字幕（ASR 转写，不臆造台词）。
- 另一语言为该字幕的**等义翻译**：语气、断句、标点跟随原字幕情绪，不新增信息、不解释画面。
- 两套共用同一条时间轴，逐条对齐；不允许因英文更长而单独改时间码。

### 2. 翻译与可读性

- 英文：口语化短句，单条 ≤ 42 字符（约 2 行），阅读速度 ≤ 20 字符/秒。
- 中文：单条 ≤ 20 字，阅读速度 ≤ 9 字/秒。
- 时间太短装不下时，优先压缩措辞（如 "I'm going to share..." → "I'll share…"），不拆碎时间轴。

### 3. 平台选择规则（内容包 `subtitleByPlatform`）

| 语言 | 平台 |
|---|---|
| `zh`（中文） | 抖音 `douyin`、小红书 `xhs`、B站 `bilibili`、快手 `kuaishou`、视频号 `tencent`、百家号 `baijiahao`、微博 `weibo`、虎扑 `hupu`、知乎 `zhihu`、支付宝 `alipay`、大鱼号 `dayu`、雪球 `xueqiu` |
| `en`（英文） | YouTube `youtube`、TikTok `tiktok`、Instagram `instagram`、Facebook `facebook` |

规则：
- 国内平台默认中文；海外平台默认英文，即使视频配音是中文（面向当地受众或算法推荐）。
- 用户明确指定某平台语言时，以用户指定覆盖默认。
- 只生成部分平台时，`subtitleByPlatform` 只写已生成平台。
- 只做单一语言时，`subtitles` 只保留该语言，可省略 `subtitleByPlatform`。

### 4. 内容包写法

```json
"subtitles": {
  "zh": { "srt": "subtitles.zh.srt", "vtt": "subtitles.zh.vtt" },
  "en": { "srt": "subtitles.en.srt", "vtt": "subtitles.en.vtt" }
},
"subtitleByPlatform": {
  "douyin": "zh", "xhs": "zh", "bilibili": "zh", "youtube": "en", "tiktok": "en"
}
```

发布环节按平台读取 `subtitleByPlatform[<platform>]`，取 `subtitles[<lang>]` 下的 SRT/VTT；不得把中文平台配英文字幕、海外平台配中文字幕（除非用户指定）。
