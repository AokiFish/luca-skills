# 道具逻辑工坊（Prop Logic Workshop）

目标：为你的双胞胎版本找到「属于自己的道具逻辑」——一个能同时承载 **身份信号、触及扩展、无意面具** 三件事的道具方案。老太太玩法的精髓（把「绅士从容」换成「老人顽皮」、把「无意」翻成「蓄意」却被身份消解攻击性）就是在这里被设计出来的。

## 四步法

1. **拆原版道具的三重功能**，写下来作为标尺：
   - 身份信号：一眼认出是谁（拐杖 → 绅士）；
   - 触及扩展：把手够不到的变成够得到的（拐杖勾回远处的球）；
   - 无意面具：让动作看起来顺手非刻意（「拐杖自己碰到的」）。
2. **给每个 twin 各配 / 共用一个道具**，逐条满足上面三重功能。两个 twin 的道具必须成组（同款不同用，或同功能反方向）。
3. **温差测试**：这个道具能否让两人对同一件事露出「不同的理解」？露不出温差，换。
4. **反转测试（可选，老太太玩法）**：能否把道具的原意翻转？「无意」变「蓄意」但被身份消解攻击性？能翻，记忆点更强。

## 三类起手方案（仅供参考，不是答案）

| 方案 | 道具 | 为什么成立 | 温差来源 |
|---|---|---|---|
| **对称同款** | 两人都拿绅士拐杖，一个捣一个修 | 最贴原版；直接演示「无意行善」被拆成两人合演 | 同道具、反用法：一个「碰歪」一个「拨正」 |
| **对称反功能** | 一个泡泡机（制造混乱），一个粘毛器 / 小扫把（收拾） | 成对美感 + 反差功能，视觉上一眼是「一组」 | 一个在「制造浪漫」，一个在「清理灾难」 |
| **共享单道具** | 一根双头拐杖 / 一个行李箱（A 踢倒，B 扶正） | 物理纠缠天然制造接抛，两人被道具绑在一起 | 同一件东西，一个毁一个救，争抢感即笑点 |

## 道具红线

- 必须一眼可读身份，否则重来（G1）。
- 必须能在「随手半径」内制造 / 收拾麻烦（G3）。
- **绝不能真有攻击性 / 危险性**——老太太玩法的精髓是「身份消解攻击性」，你的道具也要安全无害；攻击性只存在于「看起来像」的错位里（弹簧拳头看着吓人但不伤人）。越「像武器但无害」，温差越大。
- 优先选「日常、可被误读」的物件：拐杖、玩具枪、泡泡机、扫把、行李箱、雨伞、耳机——越普通，反转越惊喜。

## 输出物

工坊结束时，固定一份「道具卡」写进蓝图开头：

```
道具卡
- 恶作剧T 道具：<道具>，身份信号=<…>，触及=<…>，无意面具=<…>
- 善后T 道具：<道具>，身份信号=<…>，触及=<…>，无意面具=<…>
- 成组方式：对称同款 / 对称反功能 / 共享单道具
- 反转点（若有）：<原意 → 翻转后>
```
