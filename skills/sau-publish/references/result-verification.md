# 发布结果核验

## 一、为什么必须核验

发布日志的“发布成功”只是 CLI 自己的判断。实际遇到过：提交阶段反复弹短信验证码、验证码并未真正输入，CLI 重试后仍打印“视频发布成功”。只有后台作品页的状态才是证据。

## 二、核验方法

### 方法 A：脚本核验（推荐）

```powershell
cd D:\Mydata\github\social-auto-upload
.\.venv\Scripts\python.exe <skill>/scripts/verify_douyin_post.py --cookie "cookies\douyin_<account>.json" --out "_verify_post.png"
```

脚本行为：用 cookie 打开 `creator.douyin.com/creator-micro/content/manage`，打印页面标题与正文头部，并截图。然后人工/视觉检查截图。

### 方法 B：手动核验

浏览器打开创作者中心 → 内容管理 → 看最新作品。

## 三、判定标准（全部满足才算发布成功）

1. 作品列表出现本次标题（允许显示截断，但开头结尾要对得上）。
2. 状态为 **已发布**（不是“审核中”“草稿”“仅自己可见”）。
3. 时长为视频实际时长（如 00:15）。
4. 发布时间与本次操作时间一致。
5. 描述开头与内容包 `douyinDesc` 一致。

## 四、异常处理

| 核验结果 | 处理 |
|---|---|
| 有作品、已发布 | 报告成功，附截图/状态 |
| 有作品、审核中 | 如实报告“已提交，审核中”，不要宣称已公开 |
| 无作品 | 检查验证码/网络；可重跑一次，但先确认没有重复草稿 |
| 出现两条相同作品 | 停止，向用户说明并请其决定保留哪条 |
| 状态“仅自己可见” | 检查发布时的可见范围设置 |
