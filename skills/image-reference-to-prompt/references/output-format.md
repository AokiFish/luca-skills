# 输出格式与质量检查

## 视觉分析卡

- **画幅与裁切：**
- **主体位置/大小：**
- **头部方向 / 眼神方向 / 表情：**
- **关键物件及位置：**
- **前景 / 主体焦平面 / 背景：**
- **光线方向与软硬：**
- **主色 / 辅色 / 点缀色：**
- **材质与成像质感：**
- **3–5 个不可丢失的视觉锚点：**
- **推断或不确定项：**

## 提示词结构

`主体与成像类型 → 构图裁切 → 姿态/脸部/视线 → 关键物件关系 → 光线/景深 → 色彩/材质 → 背景 → 必要排除项`

## 发送前的 8 项检查

- [ ] 构图和主体落点准确
- [ ] 裁切边界准确
- [ ] 头部方向与眼神方向分开写
- [ ] 关键物件左右位置、遮挡和景深正确
- [ ] 光线方向正确
- [ ] 清晰区与虚化区正确
- [ ] 没有把推断写成事实
- [ ] 提示词可直接复制使用，且没有冗余形容词
