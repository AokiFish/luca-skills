# 12 套封面模板 Prompt 库

所有模板统一规格：**3:4 竖版**（小红书/视频号/抖音封面通用），**真实人像 + 超大粗体标题**，标题不挡脸。
调用方式：把对应模板的 `ref_url` 作为 `image_reference_url_list` 第一张传入 `image_edit`；若要替换本人照片，把用户照片作为第二张传入，并在 prompt 末尾加人物替换句。

## 通用约束（每套 prompt 末尾都要带）

```
3:4竖版封面，真实人像摄影质感，自然柔光，高清锐利，标题文字清晰可读、不遮挡人物面部；不加手机外框、不加平台按钮、不加UI外壳。
```

## 人物替换句（用户提供本人照片时追加）

```
主角五官身份严格参考图2，保持图2的脸型、发型、五官特征，只更换图2人物所处的姿势、服装与场景，不要把图2背景带进来。
```
