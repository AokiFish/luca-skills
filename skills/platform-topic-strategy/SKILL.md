# platform-topic-strategy

选题前先读总纲，再逐平台判定；不许一题打天下原样分发。

## 规则

1. 选题第一步读总纲 ~/workspace/luca/self-media/topics/platform-topic-strategy.md（空间「平台选题策略」是同一份的镜像），再读平台档案；逐平台独立判定：优先 / 可翻译 / 跳过；跳过的平台不生成稿。
2. 证据等级标清楚：小红书 = 调研定版；公众号/知乎/掘金/即刻/X = 档案口径；视频号 = 先行口径（40–55 岁、关系链分发、信任共鸣、大众实用；开发者硬核降级）；YouTube/抖音/B站 = 待调研·视频阶段占位。先行/占位口径绝不说成已定版。
3. 平台不限国内，而是国内外高质量图文平台。语言分工：中文母版给知乎等中文平台；英文只给 X / Medium / Substack / dev.to 等海外平台。
4. 小红书选题独立：受众 18–34、约 70% 女性、搜索驱动「抄作业」；优先 AI 办公/职场效率 > 提示词/模板合集 > 生图对比教程 > 学生向学习 > 工具测评；开发者硬核垫底，须先场景翻译成普通人具体任务，翻译不成立就跳过。变现只走平台内路径（蒲公英商单/店铺数字产品），不导流。
5. 小红书图文包：标题 ≤20 字、图卡 3:4、正文 300–600 字、话题 5–10 个、无外链不导流。

## 验收

- 选题记录写明总纲版本 + 逐平台判定；跳过平台有理由；先行/占位口径已标注。
