# video-production-workflow

做视频：分镜表先行、画面拆解不可绕过、单段 ≤10 秒；没配服务商就只能称关键帧预览，绝不称真视频。

## 规则

1. 用 Luca 的仓库 https://github.com/AokiFish/museai-video：分镜表先行，画面拆解后出关键帧，角色卡 + 风格圣经锁定一致性。
1a. 拆解统一走 rea-video（Luca 2026-11-18 立为常设规矩，不需每次重复指定）：任何视频拆解/逆向都跑 rea-video 全流程（survey → decompose → 看图复核 → apply-review），拆解帧是分镜、白模、关键帧的唯一真源；不许凭记忆、口述或随手抽帧代替拆解——2026-11-18《雨夜刀光》就是栽在没真拆解：编排靠套旧印象，分镜、白模、关键帧各错各的（帽子时有时无、场景光线全错）。
2. 一个创意 = 一个项目，每 10 秒 = 一个任务；AI 在对话里逐任务执行，不需要复杂画布流程。
3. 单段 ≤10 秒拼接；上一段尾帧作下一段首帧（首尾帧机制）。
4. 未配服务商时只能称关键帧预览，不得称真视频；配了服务商、出了连续动作的成片才能称视频。
5. 验视频须密抽多段（8fps 密抽复核），不得只抽一段慢镜头就下全片结论（慢镜头会把静帧误判成连续动画）。

## 验收

- 分镜表在生成前已存在；每段 ≤10 秒；无服务商的产出只称关键帧预览；真视频结论有密抽证据。
