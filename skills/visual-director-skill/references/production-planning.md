# 生产计划

把创意方向变成"能被生成模型执行"的明确计划。图片与视频分别处理，但都遵循同一套底层原则：素材职责唯一、主体锁、时间轴事件结构、动作完成态、转场预算。

## 一、图片生产计划

- 由用途决定画幅与比例（社媒竖版 9:16、电商方图 1:1、海报横版 3:2 等）。
- 明确主体尺度与位置、视线、肢体语言、关键光质与方向、背景深度、色彩关系、材质、焦点层级。
- 若身份一致性重要，使用可用的角色参考/图像参考或身份工作流；仅靠文字"同一人"不足以维持一致。
- 分离**不可变主体特征**与**可换服装/地点/姿态**。
- 写一条主提示词 + 一个简短负向/避免列表，优先级清晰。
- 做系列时先定义 series bible，每图只变动选定维度。

## 二、视频生产计划（镜头表）

定义：时长、画幅、镜头数、钩子、动作弧、相机路径、连续性要求、结尾。

每镜写明：

- **时间/时长**；
- **开始状态**；
- **主体动作**；
- **相机动作**；
- **结束状态**；
- **情绪目的**；
- **连续/交接说明**；
- **生成提示词**（或指向独立提示词）；
- **已知模型风险**。

让运动有物理动机且对当前生成能力可达；复杂运动同时发生时优先拆成更简单镜头或分镜，不堆砌不可靠动作。

## 三、素材职责分配

逐项声明每份素材负责与不负责的维度，同一维度只有一个最高优先级来源：

```text
@图片1：只负责产品外观、材质与包装比例；不继承背景与画面文字。
@图片2：只负责人物身份与发型；服装按文字指令。
@视频1：只负责镜头轨迹与动作节奏；不继承人物、产品或场景。
```

没有真实附件时不得虚构编号。把"参考素材职责"写进最终提示词。

## 四、主体锁 / 产品锁 / 人物锁

- **主体/产品锁**至少覆盖：轮廓与比例、主要颜色与材质、标签/开口朝向、初始位置与持有关系、使用前后状态、禁止的形变/复制/换色。
- **人物锁**至少覆盖：身份、年龄段、发型、服装、体态、初始站位；不要用参考人物的背景污染目标场景。
- 同镜出现 3 人以上或多人都接触主体时，为每人建立 ID、差异信号（脸型/发型/服装/姿态中至少三项明显不同）、从左到右座位表与手部归属。

## 五、时间轴事件结构

每段采用：

> 开始状态 → 触发动作 → 决定性变化 → 物理/情绪反馈 → 结束状态

并说明镜头实际覆盖其中哪些环节。分开描述人物、主体、相机、环境的运动，避免动作所有权混乱。

- **切镜许可点**：观众已看见哪个完成状态后才允许离开；需要快速衔接时用"动作结果继承"，不提前截断。
- **动作完成态**：关键动作（关合、触碰、落下、入口、破裂）在切镜前出现可读完成态，或下一镜第一帧清楚继承结果；镜头数量达标但观众看不见动作完成，仍视为失败。
- **转场预算**：普通转场 0.2–0.8 秒；避免"跟随、穿越、漂浮、逐渐变成"吞掉下一段；转场桥中不超过约 0.3 秒的空白或近纯色无主体帧，目标场景在桥接元素消失前建立。
- **低运动护栏**：packshot 之外，低运动构图约 2 秒内必须出现第二状态、有效主体运动或新信息；不连续安排两个只承担凝视/倒影/微笑/慢转身的同功能氛围镜头。

## 六、镜头密度与节奏（通用参考）

不绑定任何模型，仅作为沟通基线；实际以用户指定为准：

- 短视频快节奏：约 14–18 有效镜头；
- 标准：约 11–14 镜；
- 克制电影感：约 8–10 镜。

镜头多不等于机械碎切：每镜仍需新信息、单一主要动作、可读完成态和明确接口。叙事模块 ≠ 实际镜头数 ≠ 生成段数。
