## 提示词结构

`主体与成像类型 → 构图裁切 → 姿态/脸部/视线 → 关键物件关系 → 光线/景深 → 色彩/材质 → 背景 → 必要排除项`

## 视频分镜复用 · 角色卡（配合 video-link-to-prompt）

当这张参考图要填进 video 模板的 `[主角N]` 占位符时，除上面的视觉分析卡与提示词外，额外产出一张角色卡：

- **中英文自包含角色描述**：只写稳定可辨识的外貌（物种/体态、配色、签名特征、材质渲染、表情范围），不写动作；能直接贴进 `[主角N]`。
- **禁用词 / 形体禁忌**：该角色最易被脑补错的特征，列 3–5 条显式排除（如某无翼角色禁 `wings/claws/flying`）。
- **一致性风险**：参考图只覆盖单只/单一姿态，但镜头要群体/复杂互动时的形变风险；风格不统一时的兜底句。
- **表情 / 动作幅度边界**：可做的表情与肢体幅度，供 video 模板写 `[剧情]` 动作时参考。
