## 2. 剧情梗概（第一季大结局）

北宋秦州，**种府**内一次密谋。

**林兄**（现代特种兵装束的穿越者：黑色战术背心 + 战术手套，坐在宋代木格窗室内）登门拜访**种兄**（蓝袍束发的种家子弟）。两人复盘秦家的死局：秦家花钱雇蒙古人办事却反被折损大半人手，残部恼羞成怒夜入秦府杀主劫财后远遁——林兄要借此**扮成蒙古人**动手，把这层皮套在秦家自己头上。

种兄点破：林兄今日来，不是求他帮忙杀人，而是求他**别拦**。种兄顺势"装聋作哑"——理由是种家军已奉调西北**德顺军**方向，因**西夏**近来不安分、边境正在调兵，州府短期内顾不上城里这些陈年旧账。两人成交：种兄撂话"今夜你没来过种府"，林兄承诺"不会把尾巴留在城里"。

林兄告辞，与小队汇合（**络腮胡壮汉** + **握红缨枪的绿裙女子**）。小队先吃饭，随即**夜骑出发，带路去秦府**灭门。结尾黑场字幕：**第一季完 / 第二季即将上线**。

核心主题：**借刀杀人 / 穿越者借古代势力矛盾完成复仇**，靠"蒙古人背锅 + 边境战乱转移官方注意力"双保险。

## 8. 风险与已知局限

1. **ASR 同音词校正**：转写存在同音误识，已按剧情上下文校正，主要项：
   秦恒→**秦珩**（帧内烧录字幕为秦珩）、岂会不查、索债、远遁、扮成、横行、装聋作哑、借刀、种家军、西夏、陈年旧账、局面收不住、空着肚子、带路。
   人名/术语以**帧内烧录字幕**为准（比转写可靠）。
2. **抽帧非连续**：2s 间隔采样，打架/奔骑等快速运动以"近似"记录，精确动作建议回放原片。
3. **切点近似**：96s 室内→室内、110s 起夜外为估计值。
4. **未正脸角色**：秦珩、秦元昊、巴杜鲁仅台词提及，报告中戏份据台词推断。
5. **模型依赖**：faster-whisper 权重经 `hf-mirror.com` 镜像下载；本机 PyAV 已固定为 `12.3.0` 以兼容 faster-whisper 1.2.1（19.x 会因 `metadata_errors` 参数报错）。
