# 架构说明

## 为什么使用 Vercel Skills CLI

它是面向开放 Agent Skills 生态的通用 CLI，支持从 GitHub 安装、列出已安装 Skill、检查更新和更新，并能为多个支持的 Agent 安装。Luca 只保留薄封装，避免重复实现来源解析、安装锁和远端变化检测。

## 责任边界

- GitHub 仓库：发布 Skill 内容。
- Vercel Skills CLI：发现、安装、追踪来源、检查变化和更新。
- `scripts/luca-update.mjs`：增加一个跨平台的“先检查、再明确确认”交互。
- Agent 宿主：加载和执行 Skill。
- 操作系统/调度器：可选地触发定期检查。

## 版本策略

第一阶段使用 CLI 的来源/内容变化追踪，不引入额外注册中心或自建更新服务。它检测的是内容变化，不应误称为严格的语义化版本管理。

如果以后需要 `1.2.3` 版本、兼容性约束、发布渠道、签名校验或逐项审批，再增加元数据层。届时每个 Skill 仍不需要自己的更新器。
