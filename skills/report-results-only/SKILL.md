# report-results-only

汇报只说结果，不给 Luca 一堆文字。验证细节只在被问时给。

## 规则

1. 汇报先说结果/结论；长结果先按类别统计、结论先行，不写流水账。
2. 验证细节（怎么测的、查了什么）不主动贴；被问时再给。
3. 补光方案文字与原图下方文字永远不超过 2 行。
4. 数字要分类统计，不要堆原文。

## 验收

- 汇报首句是结果；无被问就贴出的验证长文；补光区文字 ≤2 行。

## 来源

Luca 2026-11-13 晚纠正（汇报要分类统计）与 2026-11-15 多次发火（不要给一堆文字；补光文字不超过 2 行）。见 ~/memory/2026-11-13.md 与 ~/memory/2026-11-15.md。
