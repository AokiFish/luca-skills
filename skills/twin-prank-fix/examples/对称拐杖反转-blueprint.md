# 双胞胎蓝图 · 对称拐杖反转（示例）

> 本文件是 `twin-prank-fix` Skill 的**完整范例输出**，演示如何把「绅士拐杖不经意行善」改写为「一个恶作剧、一个善后」的双胞胎版本。可直接作为你第一条视频的起跑稿，长相由参考图锁定，这里只用占位符。

## 道具卡

- **恶作剧T 道具**：绅士拐杖。身份信号 = 绅士/从容；触及 = 勾、挑、挡远处小物；无意面具 = 「拐杖自己碰到的」。
- **善后T 道具**：同款绅士拐杖。身份信号 = 同款绅士；触及 = 勾回、拦、拨正；无意面具 = 「路过顺手」。
- **成组方式**：对称同款（同道具反用法）。
- **反转点**：原版「无意行善」被拆成两人合演——一个把善举的「因」反过来（制造麻烦），一个接住「果」（恢复秩序）。

## 人设卡

- **恶作剧T**：哪吒式顽童。哼歌、坏事后无辜环顾。职能 = 抛出荒诞。
- **善后T**：冷面执行型。零台词、翻白眼、手上不停。职能 = 接住并恢复秩序。
- **温差方向**：A 越天真无害，B 越冷静嫌弃。

## 视觉语法命中清单

- [x] G1 两拐杖一眼读「绅士」且同款成对
- [x] G2 恶作剧与善后都「无意」（拐杖自己碰到）
- [x] G3 事件全在随手半径，两人同半径同口气
- [x] G4 善后T 零台词靠翻白眼/叹气，恶作剧T 哼歌/口哨
- [x] G5 每拍温差：无辜 vs 嫌弃、鼓掌 vs 拉人
- [x] G6 修补在恶作剧同一口气内落地（镜5被缠仍修）

## 风险 / 下版迭代

1. 两双胞胎长相需靠参考图锁定一致性，生成时加 `no extra limbs, consistent twin appearance` 防护。
2. 「无意」易被模型读成「刻意搞笑」——提示词强调 `accidental, as if the cane moved on its own`。
3. 镜5 长镜连锁动作多，建议拆成 2–3 个生成单元，用结尾定格锚点衔接。
4. 若想更「哪吒」，把恶作剧T 的哼歌换成自言自语式碎碎念（仍不出完整台词）。
