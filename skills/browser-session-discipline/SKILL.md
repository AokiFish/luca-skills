# browser-session-discipline

浏览器会话和标签页别留垃圾。一次任务一个连续会话，用完就关。

## 规则

1. 每次开标签页，用过就自己关掉；需要时再开，绝不留一堆垃圾标签。
2. 同一个网站同时最多 2 个标签页，超了不准开。
3. X 设备浏览器：每批全程只用一个标签页（地址栏跳转，绝不开新标签），结束即关窗；每批结束只留首页标签页。同站最多 2 个标签页。
4. 只读核查优先用 curl、不开浏览器。

## 验收

- 一批工作结束时标签页已关完，只剩约定保留的首页标签；多开的标签要说明理由。
- 结束时留下一堆未关标签即不合格。
