# 全平台文案规则总表

> 用途：生成内容包前查这张表，按平台硬限制裁剪标题、描述、标签。
> 置信度标注：[官方] = 平台开放平台/官方文档明确；[实践] = 平台运营指南或主流第三方实测建议；[待核实] = 无公开硬限制，以发布页为准。
> 平台代码与 social-auto-upload 的 CLI 平台参数一致。

## 使用方法

1. 生成某平台文案前，先按本表确定"标题上限 + 描述上限 + 标签数量"。
2. 字数统计口径：中文按字计，英文/数字按字符计；小红书标题按"字"（含标点）计。
3. 生成后用 `scripts/validate_pack.py` 校验；超出上限的字段必须重写，不允许硬截断。
4. 标 `[待核实]` 的平台，交付时注明"以发布页实际限制为准"。
