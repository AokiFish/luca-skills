# 质量检查与定向修正

把"好不好"拆成可逐项判定的维度，而不是一句"看起来廉价"。先判硬约束，再判概念与执行，最后只报告最高影响的 1–3 个缺陷。

## 一、质检维度

### 1. 事实与合规边界
- 是否区分用户事实、合理假设与 `【待补】`？
- 是否没有编造销量、功效、认证、数据或品牌事实？
- 单一核心主张是否只有一个？视觉证明是否能被画面看见，而非只靠文字宣称？

### 2. 硬约束
- 用户要求的主体、必露元素、画幅、比例、时长、禁区是否全部满足？
- 是否未引入用户禁止的内容？

### 3. 概念与独特性
-  intended 视觉想法是否可读？
- 是否有可记忆的焦点关系，还是看起来泛化？

### 4. 构图与层级
- 注意力是否被有意引导到单一焦点？
- 是否存在无目的的元素堆砌？

### 5. 主体/人像可信
- 视线、解剖、手、姿态、皮肤、头发、服装与身体接触是否合理？
- 身份是否与锁定特征一致，有无换脸/换装/瞬移？

### 6. 光与材质可信
- 光方向是否一致，阴影是否合理？
- 材质是否可读，有无糊成一团或死黑/死白（除非刻意）？

### 7. 系列一致性
- 身份与视觉语言是否连贯？
- 每帧/每镜是否只变动预定维度？

### 8. 平台/用途适用
- 裁切安全、主体可见性、首帧清晰度、文字可读性（若涉及）是否满足发布要求？

### 9. 动作完成态与节奏（视频）
- 每个关键动作是否在切镜前出现可读完成态，或由下一镜继承？
- 是否存在连续低运动/同功能氛围镜头占满数秒的节奏谷？
- 转场是否在约 1 秒内完成，无超长纯色空帧？
- 开头是否已有值得继续观看的事件，而非孤立陈列？

### 10. 输出质量
- 提示词代码块内是否只有可执行指令？
- 是否避免"高级感、大片感、8K、完美"等空泛堆词？
- 可调整旋钮是否不超过 5 个且真的改变结果？
- 是否明确哪些由生成完成、哪些由后期/剪辑完成？

任一关键项失败时先修复再交付，不要用"最终效果以实际为准"代替具体风险说明。

## 二、定向修正循环

对每个缺陷：

1. **命名可见症状**（如"看起来像贴片而非参与叙事"）；
2. **给出最可能原因**，不确定时标注"假设"；
3. **选择最小有效修正**：只改相关提示词段落、参考、遮罩、关键帧或镜头；
4. **显式列出必须保持不变的部分**；
5. 若生成/检视工具可用，重新检查修正结果。

示例（通用）：

- **"看起来泛化"** → 改变视觉关系或焦点层级，而非加风格形容词；
- **"太暗"** → 明确可读曝光、提亮阴影细节、清晰主光关系；不要改概念；
- **"看起来假"** → 诊断是皮肤、视线、姿态、解剖、面料物理还是光线；不要只加"写实"后缀；
- **"不够时尚"** → 先查廓形、合身、造型连贯、姿态与编辑态度，再考虑配饰；
- **"视频显廉价"** → 查运动动机、相机路径、时机、切点、时间一致性，再考虑特效。

默认最多两轮定向修正，然后说明剩余限制并给出最实用下一步。绝不无限循环。

## 三、成片复盘（用户返回生成结果时）

- 用全片等间隔抽帧建立镜头地图；对失败动作高频抽帧，测量实际切点/转场边界；
- 区分成功层与失败层；
- 输出 `保留项`、`唯一主修层`、`重试指令`；
- 只修证据指向的层，不推翻已成功的产品、人物、光线或节奏。
