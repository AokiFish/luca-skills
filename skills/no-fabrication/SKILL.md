# no-fabrication

第一方证据或 nothing。不知道就写不知道，不许用看似合理的数字填空。

## 规则

1. 无法核实的指标留空，不许编；厂商自报数字标注「自报」/「未经独立复现」；未知标「未核实」，绝不猜。
2. 用户亲口点名的人物，账号必须用第一方证据（本人自挂链接）核；交付前指挥官亲自抽查锚点人物。教训：海辛的 X 是 @ring_hyacinth（本人 GitHub 自挂链接为准），不是二手名单里的 @haibun；全量复核 29 个账号改了 4 处。
3. 构建方/工人自称「已核证」「已按新门槛复筛」不能直接转述——独立核验后再报；无原帖无日期的占位条目是伪条目，直接打回。
4. 不要在核实服务端保存状态前就断言用户看到的是旧窗口；用户报告的缺陷先当真的查。
5. 不要把二手名单、机器生成的整齐列表当事实（「14 个 bot」是两人合计编制，不是官方清单）。

## 验收

- 交付物里的每个数字/账号/日期都能指到具名的一方来源，或已标 未核实/自报；无来源的数字不存在。
