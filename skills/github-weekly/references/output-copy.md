# 标题与配套文案模板

按 @Oraink灵砚 风格输出，供发到 YouTube Shorts / 小红书 / 公众号。

## 标题

```
Github本周开源热榜：{亮点1}、{亮点2}、{亮点3}...：{月份}第{周数}周 Top5
```

亮点关键词从每个项目 desc 提炼，2-4 字短语（如"AI逆向工程""本地语音克隆""多Agent工作台"）。

## 正文

```
1｜{项目名}：{2-3 句话介绍：是什么 + 给谁用 + 为什么火}。链接：https://github.com/{owner}/{repo}
2｜{项目名}：{...}。链接：{...}
3｜{项目名}：{...}。链接：{...}
4｜{项目名}：{...}。链接：{...}
5｜{项目名}：{...}。链接：{...}

{月份}第{周数}周 Github 开源热榜 Top 5，覆盖{领域1}、{领域2}、{领域3}、{领域4}和{领域5}，{频道名}替你捞重点。
```

## 规则

- 亮点关键词从项目 desc 提炼，2-4 字短语。
- 正文每个项目 2-3 句话，不要太长，说清"是什么+给谁用+为什么火"。
- 结尾一行总结覆盖领域，署名频道名（默认"豆包"，或用户指定名）。
