# 提示词编译

把生产计划编译成"当前生成环境能执行"的提示词。本模块刻意不绑定任何具体视频/图像模型：所有生成能力都通过"当前 Agent 原生能力"抽象路由。

## 1. 原生生成能力路由（关键兼容性）

- 需要实际渲染时，使用当前 Agent 或宿主环境已提供的**最高优先级原生图像/视频生成能力**。
- 用户明确指定且当前可用的生成工具优先。
- 用户未指定时，遵循当前 Agent 的原生工具优先级；**不在 Skill 中硬编码任何供应商或模型名**（如具体图像模型、视频模型品牌）。
- 宿主未公开底层模型名称时，只称为"当前 Agent 可用的生成能力"，不得猜测或虚构模型名。
- 当前 Agent 没有可调用的生成能力时，输出一条完整可复制的提示词与素材清单，明确说明本轮**未实际生成**。
- 不为了生成自动安装插件、注册外部服务或切换供应商，除非用户明确要求。

## 2. 编译原则

- **策略解释留在代码块外**：代码块内只放可执行指令，不混入分析、受众说明或选择理由。
- 多个提示词各自独立完整，不引用"同上"或未定义的上一段描述。
- 正向动作清楚时，负面约束才有意义；只写与当前镜头高风险相关的负向项，不堆砌通用负面词。

## 3. 提示词结构（按顺序，不留空标题）

1. 成片规格与生成方式（画幅、时长/张数、直出或预览后生成）；
2. 一句导演意图；
3. 参考素材职责（见下方写法）；
4. 主体/产品/人物锁；
5. 多场景或高密度接力片的场景锚、光色弧线与全局运动向量；
6. 按时间顺序的镜头/动作；
7. 摄影、光线与表演；
8. 声音（若有）；
9. 连续性与必要负面约束；
10. 结尾状态或 packshot 目标。

## 4. 素材职责写法

```text
@图片1：只负责产品外观与材质；不继承背景与画面文字。
@图片2：只负责人物身份与发型；服装按文字指令。
```

同一维度只能有一个最高优先级来源；没有实际附件时不得虚构编号。

## 5. 摄影与光线

只指定对叙事有用的摄影信息：景别与机位关系、一个主要运镜、对焦对象与必要焦点变化、可解释的真实光源、材质如何响应光线、有意保留的轻微手持/运动模糊/曝光变化。不要同时要求手持纪实、机械臂稳定、快速环绕和微距特写。

## 6. 负向约束示例（仅高风险相关）

- 主体/产品不变形、不复制、不换色；
- 人物不换脸、不换装、不瞬移；
- 不添加未提供的 Logo、包装文字或字幕；
- 不出现额外人物、额外手指或错误持有关系；
- 不重复已经完成的动作。

## 7. 分镜/关键帧预览模式（可选）

当用户选择"先预览后生成"时：

- 先交付无数字、无文字、无标签的纯画面分镜（默认 3×3，阅读顺序从左到右、从上到下对应第 1–9 格）；
- 图片内部不绘制镜号、时间码、面板标题、字幕、箭头、图例、水印或其他索引标记；编号与逐格说明只写在图片外的分镜表；
- 交付预览后暂停，等待用户确认再编译最终提示词；
- 若作为后续生成参考，视频提示词中单独声明阅读顺序，并禁止继承参考图中的排版标记。

## 8. 能力边界

具体模型的最长单次时长、分辨率、多模态数量、价格与编辑能力因入口而异。用户询问当前参数或实际执行时，先核对当前使用的平台入口；无法核实时标注为"平台能力待确认"，不把旧版本或其他入口的限制当作当前事实，也不承诺模型能力或生成效果。
