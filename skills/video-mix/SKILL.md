# video-mix

把一个目录里的 N 段短视频（通常是 AI 生成的 5–15 秒片段）按文件名顺序拼成一个完整长视频，**抹掉原音轨**，按各段画面情绪重新生成一段对齐节奏的背景音乐。

## 兼容性

- 跨 Agent：不调用任何平台私有 API，音频生成走"当前 Agent 原生音频生成能力"。
- 跨平台：脚本为 Python，依赖 ffmpeg + ffprobe（已在 PATH）。
- 输出兼容：H.264 High + AAC LC，`-movflags +faststart`，可直接上传 X/Twitter、抖音、微信、B 站。

## 执行流程（给 Agent）

### 1. 拼接无声版

```bash
python <skill_dir>/scripts/concat.py --input-dir "<用户给的目录>"
```

脚本最后一行是 JSON。读它：
- `success=false`：把 `error` 原样反馈给用户（常见：分辨率/帧率不一致、目录没 mp4）。
- `success=true`（mode=concat_only）：拿到 `total_duration`、`width`、`height`、`files`。

### 2. 抽帧看画面情绪，写配乐 prompt

对目录里的每段 mp4，抽 2–3 帧（开头、中间、结尾），用宿主支持的视觉能力读画面。判断每段情绪：
- 蓄力紧张 / 空灵静思 / 激烈高潮 / 温情叙事 / 悲伤离别？
- 风格：古风武侠 / 赛博朋克 / 田园治愈 / 都市情感？
- 动作类型：拉弓、挥剑、跳舞、奔跑、对话、慢镜头特写？

按时间分段（每段约 N 秒），写一段音频生成 prompt。prompt 必须包含：
- 总时长（= `total_duration`，传给宿主的 duration 参数）
- 风格定位（一句话，如"武侠电影原声 / 治愈系钢琴 / 赛博朋克电子乐"）
- 按时间分段的情绪描述，每段标 BPM 或节奏要求
- 明确"纯器乐、无人声"或"含少量人声"
- 结尾收束方式（重击收尾 / 渐弱留白 / 戛然而止）

prompt 模板（以三段剑舞为例，按实际段落改）：

```
一段<总时长>秒中国古风武侠电影配乐（cinematic wuxia），纯器乐，无人声。
节奏与情绪结构严格按三段：
- 0到{a}秒：<情绪，如：低沉太鼓单点重击 + 弦乐渐强，肃杀蓄力感，BPM约60>
- {a}到{b}秒：<情绪，如：箫独奏悠扬旋律，节奏舒缓，空灵凄美，BPM约70>
- {b}到{c}秒：<情绪，如：大鼓连击 + 琵琶轮指 + 古筝刮奏，节奏骤升140BPM，剑影翻飞>
最后2秒<收束方式，如：重击收束 / 渐弱留白>。
风格：<参考电影/质感，如《英雄》《十面埋伏》>，全用传统乐器加电影弦乐组，不要电子合成器音色。
```

### 3. 生成配乐

**使用当前 Agent 提供的音频生成能力**（不指定具体工具名，由宿主路由到对应模型）：
- duration 传 `total_duration`（整数秒）。
- prompt 用第 2 步写的内容。
- 把返回的音频 URL 下载到 `<目录>/_work/music.wav`。

### 4. 混合输出

```bash
python <skill_dir>/scripts/concat.py \
    --input-dir "<用户给的目录>" \
    --music "<目录>/_work/music.wav"
```

脚本输出最终 JSON，含 `output_path`、`output_duration`、`output_size_bytes`。

### 5. 抽帧验证并交付

- 对 `output_path` 抽 2–3 帧（开头/中间/结尾），确认画面正常、无黑屏、无错位。
- 按宿主的交付规范把视频文件交给用户（如 Doubao 用 RichMediaCard，其他 Agent 直接给文件路径）。
- 正文简短说明：段数、总时长、分辨率、配乐三段式结构、保存路径。

## 边界

- **只拼接同分辨率同帧率**。脚本会校验，不一致直接报错让用户先统一规格，不要硬拼。
- 原音轨一律丢弃（`-an`），不要保留原 AI 音轨再混音——用户要的是"重新配乐"。
- 中间产物（抽帧、merged_silent.mp4、music.wav、concat.txt）都在 `<目录>/_work/` 子目录里，不要散落到用户目录根。
- 不要顺手做字幕、转场特效、变速——用户要再加时再说。
- 音乐生成失败或时长对不上时，用 ffmpeg `-shortest` 自动截断；不要为了凑时长硬拉伸音乐。
- 目录路径含中文/空格时，脚本已用引号包好，调用时用引号包起来。

## 已知限制

- 目前配乐是按"段落情绪"对齐，不是逐帧动作检测对齐。如果用户要"每一剑都踩在鼓点上"那种级别的对齐，需要额外用 librosa 分析动作重拍点（当前脚本未做），遇到这种需求明确告诉用户并询问是否升级。
- 音乐生成走宿主原生能力，不保证严格 BPM 卡点；prompt 里的 BPM 是参考方向，生成结果以实际为准。
