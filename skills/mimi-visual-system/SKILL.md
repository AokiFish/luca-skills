# mimi-visual-system

咪咪视觉系统 v1.1。先建统一系统再出单品，系统是设计出来的不是采样拼出来的：身份 → 资产 → 继承。

## 规则

1.  canonical 咪咪是 Luca 上传的三视图里那只写实奶油英短：圆脸大眼、粉色领结领 + 金铃铛。软 3D Q 版包是已归档的备选，不是主线。
2. 配色：主色 Deep Pine 夜松 #0C1F18，搭档晨雾鼠尾草 #E7EEE0；翡翠 #0B5D40 只作储备；陶土/金退役为设计色（金只留在猫铃铛上）。53 组对比搭配零 FAIL。
3. 封面/关键视觉永远以内容主体为明星；咪咪只是角落辅助记忆元素，绝不抢镜。
4. 咪咪的表情是情绪导向：夸张、丰富的情绪可以，但必须朝向主体（目光、手势、身体朝向主体），让猫的兴奋衬托主体重要，不与主体竞争。
5. Rule F：正文默认不出现咪咪；正文里出现必须小、融入场景、在自然叙事节拍上；大幅居中猫图突兀、破文体，禁止。角色表灰底是制表惯例，不是场景底。
6. 品味：禁用黄色/金色主导（显土），用绿；不把猫框进框/卡片，要融入场景。
7. 机械 Checker PASS ≠ 审美合格：视觉工作须有真实审美标准，全面制作前先让 Luca 看选项。

## 验收

- 封面主体是内容主角、猫在角落朝向主体；无黄色主导；猫未被框进卡片；Luca 已看过选项。
