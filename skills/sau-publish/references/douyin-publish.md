# 抖音发布（douyin）

## 一、视频发布命令

```powershell
sau douyin upload-video --account <name> --file "<mp4>" --title "<标题>" --desc "<描述>" --tags "a,b,c" --headed
```

| 参数 | 必填 | 说明 |
|---|---|---|
| `--account` | 是 | 本地账号别名 |
| `--file` | 是 | 单个视频文件，每次一个 |
| `--title` | 是 | 标题，实践 30 字以内 |
| `--desc` | 否 | 描述，话题不堆进正文 |
| `--tags` | 否 | 话题，英文逗号分隔，3–5 个 |
| `--schedule` | 否 | 定时发布，格式 `YYYY-MM-DD HH:MM`；不传即立即发布 |
| `--thumbnail` | 否 | 封面图路径 |
| `--headed` | 建议 | 当前环境必须用有头模式 |

## 二、执行顺序与日志判读

1. `检查 cookie、视频文件、封面和发布时间` → `上传前检查通过`
2. `开始搬运视频` → `已经进入 version_2 发布页面`
3. `开始填标题、描述和话题` → `一共贴了 N 个话题`
4. `视频已经传完啦`
5. `自主声明已选择「内容由AI生成」`（含 AI 内容时应有这行）
6. `正在冲刺发布视频` → `视频发布成功`

第 6 行之后仍需按 `result-verification.md` 核验，**日志成功 ≠ 作品上线**。

## 三、短信验证码

提交阶段可能弹验证码：

- CLI 自动点“获取验证码”，并提示把验证码写入项目根 `verify_code.txt`。
- 收到短信后写入文件（纯数字，单行），CLI 会继续提交。
- 若没写文件，CLI 会重试若干次；有时仍能提交成功，但仍需核验。

## 四、AI 内容声明

抖音要求 AI 生成内容标注。CLI 会自动选择「内容由AI生成」；如果日志没有这一行，到发布页手动勾选后再提交。

## 五、图文发布

```powershell
sau douyin upload-note --account <name> --images "a.jpg" "b.jpg" --title "<标题>" --note "<正文>" --tags "a,b" --headed
```

- 最多 35 张图，不支持 GIF。
- 标题、正文、话题规则同视频。

## 六、常见错误

| 现象 | 处理 |
|---|---|
| 启动即退出、无日志 | 检查是否漏了 `--headed`（headless shell 缺失） |
| `cookie文件已失效` | 重新 `login --headed` |
| 反复弹验证码 | 写 `verify_code.txt`；仍失败则手动在浏览器完成 |
| 报告成功但后台无作品 | 核验后台；确认后按需重发，不重复上传 |
