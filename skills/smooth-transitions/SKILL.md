# smooth-transitions

切换必须平滑，不许生硬跳变。所有界面切换都必须带过渡动画，禁止瞬跳。

## 适用范围

轮播箭头、自动轮播、标签页、横向滚动行、滑杆、灯箱开合——一切视图切换。

## 规则

1. 任何视图切换都必须有过渡动画：transform（translateX）和/或 opacity 的 CSS transition，禁止直接换内容。
2. 时长：小切换 90–200ms；整窗滑动 200–300ms。缓动用 ease-out 或 cubic-bezier(0.22, 1, 0.36, 1)；禁止 linear 与无缓动。
3. 复用已有先例：换装空间服装行 v45——滚轮设目标位、约 90ms 指数缓动、拖动松手带惯性；新切换先照这个标准做，不要重新发明。
4. 自动轮播的每一次推进也要动画，和手动点击同一标准。
5. 只加过渡，不改布局、不改数据、不改定时、不改其他行为。

## 验收

- 探针/真机目验：点箭头能看到窗口滑过去，不是瞬换；自动推进同样滑过去。
- 只做了代码验证时必须明说，留给 Luca 在真机上看一眼。
- maker ≠ checker：改的人不自己判平滑。
