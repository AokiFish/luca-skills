# 参考诊断

把素材"看明白"再动手。诊断的核心是分离三层：先记录可观察事实，再给出解释，最后才转成制作指令。绝不在事实层混入推测。

## 一、图像诊断

1. **第一印象概念**：一句话说出这张图最想传达的东西。
2. **仅记录可见事实**：主体位置/尺度、视线、姿态、手势、服装轮廓/材质、环境、构图、光线、色彩关系、质感、任何文字/图形。
3. **情绪解读**：提出一个主要情绪解读，至多两个次要解读。
4. **证据对照**：列出支持与反对主要解读的证据。
5. **视觉要素分级**：
   - **核心**：改动它很可能改变概念；
   - **支撑**：强化概念；
   - **灵活**：改动不破坏概念。
6. **区分度判断**：哪些独特、哪些泛化。
7. **转译配方**：把结论整理成可迁移的视觉配方（见 [creative-direction.md](creative-direction.md)）。

## 二、视频诊断

1. 先完整观看/检视整段（工具支持时）；不靠截图臆断。
2. 在真实切点处拆分；长镜头按有意义的动作阶段拆分。
3. 记录：主体运动、相机运动、景别、时长、转场、声音/文字线索、情绪功能。
4. **区分可见变化与推断原因**：若不确定尺度变化是相机运动还是主体运动，标注"不确定"，不强行定性。
5. 标出钩子、推进、转折点与结尾。
6. 不把通用模板硬套到源素材上。

## 三、通用规则

- 事实层只写"能看见/听见的"，不写"应该表达"。
- 解释层用"可能/疑似"前缀，可被否定。
- 推断相机/镜头精确参数（焦距、光圈、快门）无依据时标注不确定，不要编造。
- 提取"关系"而非"标签"：例如"人物与墙的冷暖对比制造疏离"优于"高级灰调"。
- 把最具记忆点的视觉关系提炼为后续可复用的"视觉配方"核心。
