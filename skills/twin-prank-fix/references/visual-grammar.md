# 视觉语法框架（Visual Grammar）

这套格式的爽点不是「好人好事」，而是一套可复制的视觉句法。改主角、改道具、改时代，只要句法在，爽点就在。下面六条（G1–G6）是设计双胞胎版本时必须逐条命中的「句法」，任何一拍缺了，观众就会觉得「不对味」却说不出为什么。

## G1 道具即身份（Prop = Identity）

- 道具不是工具，是「这一眼就知道你是谁」的戏服。
- 绅士拐杖 = 阶级、从容、「与我无关」的姿态；老太太玩具枪 = 老人的顽皮与无害。
- **检验标准**：观众在 0.5 秒内能否从道具认出人物身份？认不出就换。
- **双胞胎约束**：两个人的道具要「成对」或「对称」——要么同款不同用（都拿拐杖，一个捣一个修），要么同功能不同方向（一个制造、一个收拾）。不成对，就失去了「双胞胎」这组关系的视觉锚点。

## G2 无意性面具（The Unintentionality Mask）

- 原版核心爽点：善意藏在道具的「无意」之下。观众爽在「他本可以不管，但拐杖替他做了」。
- 这是钩子的发动机。任何「善举」都必须看起来是顺手、偶然、非刻意的。
- **双胞胎反转**：恶作剧 twin 的破坏也要「无意」（哪吒式口是心非——一脸无辜）；善后 twin 的修补更要「无意」（路过、顺手）。两人的「无意」叠加，反而让整件事看起来像一连串巧合，爽点加倍。破了这个面具，就变成「刻意搞笑」，廉价感立刻上来。

## G3 触及范围（The Reach Constraint）

- 所有事件发生在道具「随手够得到」的半径内：勾回滚走的球、拦住将关的电梯、拨正倒下的路障。
- 约束制造喜剧：角色只能影响够得着的东西；够不着的就真够不着，只能用道具够。
- **双胞胎约束**：恶作剧与善后必须在同一空间半径内、同一口气内发生。修的人就在捣的人三步之内，否则「接抛」断气。

## G4 零台词表情经济（Silent Expression Economy）

- 这类视频基本无声或近无声。情绪靠停顿、眼神、微表情、道具运动承载，不靠对白。
- 善后 twin = 零台词或只有语气词（啧、叹气、翻白眼）；所有情绪靠停顿和眼神完成。
- 恶作剧 twin = 可以话多一点（哼歌、自言自语、无辜环顾四周）。
- **反差**：一个吵闹天真，一个沉默嫌弃——声音本身就在制造温差。写分镜时，给善后 twin 标「（无台词，翻白眼）」，给恶作剧 twin 标「（哼着歌）」，不要写台词脚本。

## G5 认知温差（Cognitive Temperature Gap）

- 双胞胎喜剧的发动机不是「长得像」，是「对同一件事的理解完全不同」。
- 恶作剧 twin 把混乱当正常 / 有趣；善后 twin 把混乱当对秩序的冒犯。
- **笑点 = 温差本身**。两人绝不同时同向反应，差一点就是段子，差很多就是两个路人。设计每一拍时问自己：这一拍里两人对同一件事的理解差了几度？差为 0 就重做。

## G6 接抛配合（Catch-and-Throw）

- 一个抛出荒诞行为，另一个用完全合理的反应接住。
- **时机**：接住必须在「同一口气」内落地，否则节拍死。视觉上表现为——恶作剧刚发生，善后 twin 的手已经在修了。
- **规则**：绝不两个 twin 反应雷同。一个天真一个世故、一个吵一个静、一个动一个定，温差拉满。

## 格式长度定律

- 原版 46s / 2000 万播放说明：**短 + 高密度节拍 > 长**。
- 46s 内塞 8–12 个「恶作剧 → 善后」微节拍，每 3–5 秒一个翻转。
- 结尾必须有一个「道具最后的无意之举」作为收尾 tag，呼应开头，形成闭环。

## 迁移检查清单（设计完一拍后逐条打勾）

- [ ] G1 道具一眼可读两人身份且成对 / 对称？
- [ ] G2 恶作剧与善后都看起来「无意」？
- [ ] G3 事件在随手半径内、两人同半径同口气？
- [ ] G4 善后 twin 零台词靠表情，恶作剧 twin 可出声？
- [ ] G5 这一拍两人的理解温差 > 0？
- [ ] G6 修补在恶作剧同一口气内落地？
