# audit-read-only

巡检只列疑似，绝不自动改数据；文本全对也可能图是错的，须逐件目验。

## 规则

1. 巡检/审计功能只列出疑似项，不自动改任何数据；改不改由人逐件定。
2. 文本全对不等于图对：名称、分类、英文提示词全对，图片内容仍可能是错的（精致金耳环：分类 accessory 是对的，图却是米色长袖衬衫）。疑似项必须逐件看图核对。
3. 确定性关键词自查可以接在入库路径上（信号矛盾时改判或打「分类待确认」），但自查结果是信号，不是定论。

## 验收

- 巡检输出只有疑似清单，无自动改动记录；疑似项有逐件目验结论。
