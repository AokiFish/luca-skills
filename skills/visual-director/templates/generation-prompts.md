# 生成提示词模板

把生产计划编译为可复制提示词。代码块内只放可执行指令，策略解释、受众分析与选择理由留在代码块外。

## 主提示词（图像）

```text
[画幅与比例，如 9:16 竖版]

导演意图：一句话说明本图要传达的视觉想法。

参考职责：
@图片1（如有）：只负责主体外观与材质；不继承背景与文字。
@图片2（如有）：只负责人物身份与发型；服装按文字指令。

主体与场景锁：
- 主体：廓形 / 颜色 / 材质 / 初始位置 / 持有关系
- 环境：
- 必须固定：
- 可变：

摄影与光线：
- 景别与机位：
- 主光：可解释光源方向与质感
- 色彩逻辑：

主体动作 / 姿态：
- 视线：
- 手势 / 肢体：

结尾状态：
- 主体最终呈现：

负向（仅高风险相关）：
- 不变形 / 不复制 / 不换色
- 不添加未提供的文字或 Logo
- 不出现额外人物或错误持有关系
```

## 视频提示词（按时间轴）

```text
[总时长，如 15 秒] [画幅] [直出 / 预览后生成]

导演意图：一句话。

参考职责：（同上）

主体/产品/人物锁：（同上）

时间轴（每段：开始 → 触发 → 变化 → 反馈 → 结束态）：
0–3s  钩子：第一帧正在发生的具体事件；可见变化；
3–Xs  段落：主体动作 / 相机动作 / 结束态 / 连续接镜；
...
结尾  X–Ns 收束：产品/主体稳定识别或 endboard。

摄影与光线：（每段时间共用的光色逻辑）

声音（若有）：主声音清单只出现在声音段，画面时间轴只引用 ID。

负向（仅高风险相关）：
- 关键动作在切镜前展示完成态
- 不重复已完成动作
- 不添加未提供的文字或 Logo
```

## 系列提示词（图集）

```text
系列规则（series bible 摘要）：
- 固定：角色身份 / 色彩基调 / 光线基调 / 世界规则
- 可变：服装 / 场景 / 姿态

图 01：[固定项] + [本图可变项] + [画幅] + [负向]
图 02：[固定项] + [本图可变项]
...
```

## 使用约定

- 每段提示词独立完整，不写"同上"或未定义引用；
- 正向动作清楚后再加负向，不堆通用负面词；
- 当前 Agent 无生成能力时，照常输出提示词并在交付说明中标注"未实际生成"；
- 具体模型能力（最长时长、分辨率）以当前入口为准，无法核对时标注"平台能力待确认"。
