# 案例输入：Mimi 首播翻车自我介绍（15s）

本案例演示"一条视频 → 多平台内容包"的完整流程。输出成品见同目录 `content-pack.json`。

| 字段 | 值 |
|---|---|
| 视频文件 | videos/mimi-debut.mp4 |
| 时长 / 比例 | 15s / 16:9 |
| 出镜人设 | Mimi，浅奶橘英短，粉色蝴蝶结+金色铃铛 |
| 视频内容 | 认真准备频道首支自我介绍，接连翻车：尾巴扫走提词卡、碰倒水杯，水滴打湿蝴蝶结和铃铛，最后破功卖萌求订阅 |
| 视频语言 | 英文配音（海外平台用英文，国内平台用中文改写） |
| 画面文字 | 全程无内嵌文字、无水印（字幕走外挂 SRT/VTT） |
| 记忆点 | ①首支视频社死 ②一本正经反差 ③水打湿铃铛蝴蝶结 ④破功求订阅 |
| 目标平台 | 抖音、小红书、B站、快手、视频号、百家号、微博、虎扑、知乎、YouTube、TikTok、Instagram、Facebook、支付宝生活号、大鱼号（雪球不适配，省略） |
