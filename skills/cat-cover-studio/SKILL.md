# Cat Cover Studio · 猫咪封面工作室

固定主角：**一只乳色英国短毛猫**（圆脸、大眼、粉色蝴蝶结领结、金色小铃铛），参考图 URL 见下方常量。
12 套版式与 cover-studio 完全一致，只是把"丸子头白T女生"换成这只猫。

## 主角参考图（每次调用必传）

```
CAT_REF_URL = https://aka.doubaocdn.com/s/fiPZJDqZoz
```

## 工作流

1. **问清两个变量**：
   - 标题文案：主标题 + 可选副标/标签
   - 猫咪表情/姿势偏好（默认：正面坐姿、大眼睛直视镜头；可选：趴卧、眯眼打盹、惊讶瞪眼、张嘴打哈欠）
2. **选模板**：查 `references/templates.md` 末尾速查表，推荐 1–2 个让用户拍板。
3. **拼 prompt**：读对应模板骨架，替换 `{{占位符}}`，末尾追加「通用约束」+「猫咪身份锁定句」。
4. **调 image_edit**：
   - `image_reference_url_list` = `[模板ref_url, CAT_REF_URL]`（模板图在前，猫咪图在后）
   - `width=1536, height=2048`
   - `model_version` 默认 `seedream_5.0_flash`
5. **交付**：通过 `RichMediaCard` 给用户；不满意保留模板号，只改文案/表情重跑。

## 猫咪身份锁定句（每次必加）

```
画面主角严格参考图2的猫咪：乳色英国短毛猫，圆脸、大圆眼、粉色蝴蝶结领结、金色小铃铛，毛色与五官特征与图2完全一致；只改变它的姿势、表情和所处场景，不要换成别的猫，不要把图2的灰色背景带进来。
```

## 通用约束（每次必加）

```
3:4竖版封面，真实摄影质感，自然柔光，高清锐利，标题文字清晰可读、不遮挡猫咪脸部；不加手机外框、不加平台按钮、不加UI外壳。
```

## 选模板口诀

- **讲工具/AI产品** → 01（极简灰底）或 12（上下双区，带电脑截图）
- **工具合集/盘点** → 05（图标环绕）或 11（漫画大字剪辑台）
- **大佬对决/行业热点** → 03（暗红群像，多只猫围绕主角）
- **模型/产品对比测评** → 04（电影分屏，同一只猫两种表情）
- **作品展示/案例拆解** → 06（黑橙大字+作品卡）
- **教程/社媒玩法** → 07（杂志拼贴）或 10（蓝绿撕纸）
- **学习笔记/知识管理** → 08（粉色大字界面）
- **生活/MV/户外** → 02（蓝天秋草）或 09（超现实分屏）

## 硬性约束

- 比例默认 3:4 竖版（1536×2048）；用户要 9:16 或 16:9 时按对应比例。
- 标题不挡猫脸；猫的蝴蝶结和铃铛必须保留。
- 不加手机外框、平台按钮、水印。
- 主角永远是图2那只猫，不要换成别的猫。
- **禁止用灰色背景**（包括中性灰、磨砂灰、灰底），封面背景必须用彩色/场景色，不用灰。
- **表情与动作要夸张有情绪**：猫咪不能死板呆坐，要根据话题做夸张表情和动作（惊叹、兴奋、得意、比耶、捂脸笑、举爪欢呼等），一眼看出情绪。
