# secret-handling

部署密钥与凭证：用新生成的，不用公开默认的；只存 600 权限文件，永不入库、不外露。

## 规则

1. 社区部署包内置的公开默认 UUID 绝不能用，须用新生成的 UUID/路径。
2. 密钥只存于 600 权限文件，不入库；凭证值不进记忆、不进聊天、不进日志、不进生成代码。
3. 不把凭证值放进 URL；不绕过密文/受保护访问。
4. 汇报凭证检查时只说结果，不贴值。

## 验收

- 部署配置用的是新生成 UUID；密钥文件权限 600；仓库里无凭证；汇报无凭证值。
