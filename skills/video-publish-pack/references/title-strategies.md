# 标题策略库（跨平台通用）

目标：同一视频产出多组标题备选，再按平台长度和语气裁剪。**先按策略出多个候选，再按平台规则挑最合适的，不硬改一句话。**

## A. 悬念 / 反差钩子款（点击率最高，优先推荐）

公式：**场景预期 + 意外转折 / 悬念留白**。

| 公式 | 示例 |
|---|---|
| My FIRST ... went horribly wrong | My FIRST introduction… It went horribly wrong 😹 |
| I tried to ... and messed up everything | I tried to bake a cake and burned the kitchen |
| The most awkward ... ever | The most awkward cat introduction ever 🐱 |
| 结果反转型：I planned X, but Y | I planned a vlog, but my cat took over |
| 自嘲社死型：I ruined my ... | Oops, I ruined my first video 😿 |

中文对应："第一次拍视频，结果翻车了""我本来想……结果……""最尴尬的一次……"

## B. 情绪 / 人设款（吸引固定粉丝）

公式：**Meet/介绍 + 人设标签 + 性格词**。

| 公式 | 示例 |
|---|---|
| Meet + 角色名 + 性格 | Meet Mimi! My very chaotic first video |
| 角色名 + 's + 事件 | Mimi's debut: a failed self-introduction |
| 第三人称预告 | This cat's first intro didn't go as planned |
| 人设宣告 | 我是全网最容易翻车的小猫 |

## C. 直白搞笑款（路人友好）

公式：**主语 + 动作/事件 + 翻车/搞笑结果**。

| 公式 | 示例 |
|---|---|
| 主语's + 事件 goes wrong | Cat's debut introduction goes wrong! |
| 主语 ruined/messed up + 事件 | I ruined my first video in 15 seconds |
| When + 主语 + 动作 | When a cat tries to introduce herself |

## D. 极简短标题（适配小红书、Shorts、缩略图）

≤6 个词 / ≤20 字，信息密度高。公式：**角色名 + 事件 + 情绪词**。

| 公式 | 示例 |
|---|---|
| 角色名 + Failed/Debuted + 事件 | Mimi's Failed Debut Intro |
| 情绪词 + First + 事件 | My Chaotic First Video 🐾 |
| 形容词 + 角色 + 事件 | Awkward Kitty Introduction |

## 按平台挑标题的优先级

| 平台 | 优先策略 | 长度处理 |
|---|---|---|
| 小红书 | D 极简短 + B 人设 | 压到 20 字内，emoji 保留 1 个 |
| 抖音 | A 钩子 + C 直白 | 压到 30 字内，前 8 字放反差 |
| B站 | C 直白 + A 悬念 | 25-30 字符，信息完整 |
| 快手 | C 直白 | ≤20 字，口语 |
| 视频号 | B 人设 + C 直白 | ≤30 字，克制 |
| 百家号 | C 直白 + 关键词 | 12-18 字，核心词前置 |
| 微博 | A 钩子 + 话题 | ≤30 字，带 #话题# |
| 虎扑 | C 直白 + 自嘲 | 4-40 字，玩梗 |
| 知乎 | 问题式 / 结论式 | 5-50 字，信息密度 |
| YouTube | A 钩子 | ≤100 字符，Shorts ≤60 |
| TikTok | A 钩子 | 短，前 150 字符可见 |
| Instagram | 情绪短句 | 前 125 字符可见 |

## 通用写作规则

1. 首词用强词：First、Worst、Nobody、Meet、Oops、When。
2. 数字与时长点明："in 15 seconds"、"3 fails"。
3. 情绪词前置：chaotic / awkward / wrong / failed / cute。
4. emoji 克制：每条最多 1-2 个（小红书可 1-2 个，B站/知乎尽量 0）。
5. 不剧透结局，只点"出事了"。
6. 平台标题超限时**换一个更短的候选**，不做截断。
