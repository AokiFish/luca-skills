# Visual Director Skill

一个面向 AI 视觉创作的可移植 Skill：从参考图、视频或一句话创意出发，自动完成视觉诊断、创意方向、生成指令、质量检查与定向修正。

## 快速使用

将本目录作为 Skill 安装到支持 `SKILL.md` 的 Agent/编码助手中。不同平台的技能目录和启用方式不同，请按对应平台的 Skill 安装规范放置本目录。

安装后，上传参考图片/视频，或输入一句创作想法，再说：

- `一键出品：根据这张参考图制作一组写实的时尚图片。`
- `一键出品：把这个视觉方向转成一条8秒时尚短片。`
- `分析这张图，提取可复用的视觉配方，暂时不要生成。`
- `检查这张生成图为什么看起来廉价，并只修正最主要的问题。`

## 默认行为

- 默认面向写实成年虚构模特、时尚编辑摄影与短视频。
- 尽可能自动判断，不让用户填写冗长表单。
- 优先识别少数关键视觉关系，而不是堆叠摄影术语。
- 能使用图片/视频生成工具时，继续执行到成品；没有对应工具时，输出可执行制作包，不虚报生成成功。
- 先生成、检查，再做最多两轮定向修正。
- 视觉分析中的事实、解释和传播效果假设分开处理。

## 目录

- `SKILL.md`：核心工作流和执行规则。
- `templates/creative-brief.md`：创意简报。
- `templates/visual-recipe.md`：视觉配方。
- `templates/quality-report.md`：质量检查与纠错。
- `templates/series-bible.md`：角色与系列一致性规范。
- `templates/video-storyboard.md`：视频分镜。
- `examples/example-fashion-brief.md`：示例工作产物。

## 重要说明

Skill 是 Agent 的工作流程指令，不会自行提供图像/视频生成能力，也不会自动连接未授权的外部服务。实际“一键出品”能力取决于安装环境可调用的生成、查看、文件处理和导出工具。
