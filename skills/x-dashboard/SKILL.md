# x-dashboard

X AI 信息监控看板：每天两更，只收看完能学到、能用到的；看板只展示帖子本身。

## 规则

1. 栏目 6 栏 × 每栏 Top 5：大厂动态 / 大V干货 / 新玩法·新方法 / 好用工具 / 传播最快 / AI创作者；同一帖子不进两栏。
2. 晨版 10:00 + 晚版 20:00；晚版与晨版逐条去重。按日期封存、只追加不覆盖，默认只看当天；2026-11-09 为首期，不编造往期。
3. 收录门槛：只收看完能学到、能用到的；改名/换标、玩梗 meme、纯概念炒作、纯感慨/鸡汤、只增加了解的一律不收；优先实干型（Karpathy 为标杆）。
4. 时效硬规则：原帖必须在最近 7 天内（优先 24h），超期一律不收；每条标注原帖日期。
5. 潜力贴：3–5 个尚未爆发的帖子，以普通帖子卡片呈现；次日晨版只在原卡片补 命中 / 部分命中 / 未命中 小标记，不改原文。
6. 本周十大热门：独立区，数据参考 Postel 爆帖榜本周排名，晨版每日刷新、晚版不动；同样过收录门槛。Postel 榜单数据不可靠，只作参考，须以实测的 X 原帖数据为准。
7. 展示原则：页面只展示帖子本身，不展示规则、评分方法、回验台账。卡片只留标题（链原帖）/ 作者 / 日期 / 一句话摘要 / 热度 / 链接。聚合页/转载页日期不可当作原帖日期，须以原帖/官方发布日为准。
8. 数据源：无 X 官方 API、无登录会话，靠第三方聚合站 + 公开网页交叉核对；无法核实的指标留空；厂商自报须标注未独立复现。每版末尾列完整可点击的源数据 URL，只写来源名不算完成。

## 验收

- 每张卡有日期与源链接；无超 7 天帖；晚版与晨版零重复；预测帖次日有回验标记；自报数字已标注。
