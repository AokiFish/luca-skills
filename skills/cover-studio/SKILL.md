# Cover Studio · 封面模板工作室

12 套已跑通的小红书/短视频封面模板，统一 3:4 竖版、真实人像 + 超大粗体标题。
**调用 `image_edit` 以模板图为参考做改写**，不要从零文生图（从零文生会丢模板的版式手感）。

## 工作流

1. **问清两个变量**（缺什么问什么，一次问完）：
   - 标题文案：主标题 + 可选副标/标签（直接写要显示在封面上的字）
   - 是否替换人物：用户给本人照片就传；不给就用模板默认的丸子头白T女主
2. **选模板**：根据内容主题，查 `references/templates.md` 末尾的「模板速查表」，推荐 1–2 个最贴合的，让用户拍板；用户已指定编号就跳过。
3. **拼 prompt**：打开 `references/templates.md` 找到对应模板的 Prompt 骨架，把 `{{占位符}}` 全部替换成实际文案，末尾追加「通用约束」。
4. **调 image_edit**：
   - `image_reference_url_list` = `[模板ref_url]`，若替换人物则追加 `[用户照片URL]`
   - prompt 末尾追加 templates.md 里的「人物替换句」（仅当传了用户照片）
   - `width=1536, height=2048`（3:4）
   - `model_version` 默认 `seedream_5.0_flash`；用户要更高质量再上 `seedream_5.0_pro`
5. **交付**：把生成图通过 `RichMediaCard` 给用户；如不满意，保留模板号，只改文案/配色/表情再重跑一次。

## 选模板的判断口诀

- **讲工具/AI产品** → 01（极简灰底）或 12（韩系上下双区，带电脑截图）
- **工具合集/盘点** → 05（图标环绕）或 11（漫画大字剪辑台）
- **大佬对决/行业热点** → 03（暗红群像）
- **模型/产品对比测评** → 04（电影分屏）
- **作品展示/案例拆解** → 06（黑橙大字+作品卡）
- **教程/社媒玩法** → 07（杂志拼贴）或 10（蓝绿撕纸）
- **学习笔记/知识管理** → 08（粉色大字界面）
- **生活/MV/户外** → 02（蓝天秋草）或 09（超现实分屏）

## 硬性约束（必须遵守）

- 比例默认 **3:4 竖版**（width:height = 1536:2048）；用户要 9:16 或 16:9 时按对应比例。
- 标题字必须**不挡脸**；人物五官清晰，不能糊成AI假脸。
- 不加手机外框、不加平台图标按钮、不加"小红书"水印。
- 替换人物时，**只换脸/身份，不换构图、配色、字体版式**。
- 每次只出 1 张主稿；用户要 A/B 才再跑第 2 个模板。

## 文件结构

```
cover-studio/
├── SKILL.md                    # 本文件（工作流 + 选模板口诀）
└── references/
    └── templates.md            # 12套模板完整prompt + 每张模板的ref_url
```

详细模板 prompt 与参考图 URL 全部在 `references/templates.md`，**选好模板号后必须打开该文件读取对应骨架**，不要凭本文件描述现编 prompt。
