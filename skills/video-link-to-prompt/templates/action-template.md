# 动作模板（原视频逐镜头动作拆解）

> 本文件由 `analyze_video.py` 生成骨架，需由你在**逐页阅读 `sheets/sheet_XX.jpg`** 后手工填写。
> 它是后续生成分镜与 prompt 的**唯一事实来源**：所有动作节拍必须落在真实帧上，禁止凭空脑补。

## 填写规则
- 按时间顺序、逐页（sheet_01、sheet_02 …）阅读 `sheets/` 里的缩略图，对照 `frames/` 单帧核对细节。
- 每个时间区间写**有序动作节拍 ①②③…**，每拍描述一个可见的「起承转合」（谁、做了什么、结果如何）。
- **看不清就标 `unknown`**，继续往后走，不要猜。
- 景别 / 机位 / 运动 / 声音 同样按可见证据填写（取值见下方速查）。
- 段色调：本段统一色彩关键词，跨段只在边界换一次。
- 节奏约束（来自 `analysis_bundle.json`）：约 `{{beat_interval}}s/拍`，每个生成单元（如 10s）需塞下 `{{beats_per_unit}}` 拍，不要把一个动作演满整段。

## 取值速查
- 景别：大远景 / 远景 / 全景 / 中景 / 中近景 / 近景 / 特写 / 大特写
- 机位：平视 / 仰拍 / 俯拍 / 顶视
- 运动：固定 / 推 / 拉 / 摇 / 移 / 跟 / 升降 / 环绕 / 手持 / 航拍 / 俯瞰
- 声音（无声台词视频也要标非语言音节 / 环境音 / 音乐提示）：嗯 / 咝 / 喔 / 啊 / 风声 / 鼓点 …
