# effect-improvement

效果类工作不许随机抽参数。名字不改，改后台做法。

## 规则

1. 先解析图片（原光方向、主体类型、场景、材质），再按解析结果选补光策略；解析结果要留记录。补光必须是真 3D 立体（光跟随画面几何），2D 渐变叠加不接受。
2. 不许随机抽参数；每个参数必须能从解析结果说出理由。
3. 出效果后让审美 / 摄影师 / 艺术家 Bot 分析效果并打分，maker ≠ checker——做的人不自己判好坏。
4. 以网上真正高质量的素材作参照物，对照调整、迭代训练自己，直到效果接近参照；参照来源要写明。
5. 边界：参照素材只作参照，不许批量抓取、复制参考站的演示图（版权原因）；风格对标可以，图片照搬不行。内部解析策略、材质响应、依据与出处只写 .md 规则文档，不展示在页面上。

## 验收

- 解析输出先于生成留档；参数与解析对应；独立打分已记录；参照来源已写明。
- 随机参数、只自己说好、参照来源不明，三者有其一即不合格。
