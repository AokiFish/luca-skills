# Video Reference Analysis Report

## 1. Access status
State precisely what was inspected and what was unavailable.

## 2. Creative summary
Explain the idea, hook, emotional arc, and payoff in plain language.

## 3. Shot-by-shot breakdown
Use `shot-breakdown.md`; use approximate timecodes when exact ones are unavailable.

## 4. Why it works
Explain the reusable mechanism, not merely what appears on screen.

## 5. Fixed vs replaceable
Separate durable creative rules, per-video variables, and model-specific controls.

## 6. Ready-to-use prompt
Provide a completed prompt for the requested target. If the user requested a reusable template, retain obvious placeholders.

## 7. Model settings
List only supported or verified settings separately from the prompt body. Mark unknown values as unknown.

## 8. Risks and next iteration
Give 2–4 high-value checks or refinements. Avoid a generic, lengthy list.
