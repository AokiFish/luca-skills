# space-network-wiring

空间本身独立，咪咪做衔接。连线只用细线，不合并系统、不合并数据库。

## 规则

1. 每个空间独立：自己的数据、自己的代码、自己的用途；不合并、不共享数据库。
2. 衔接只走细线：cron 体里的一行调用、调用已有 action、共享文件。连线前说清调的是哪个已有 action、回写到哪里。
3. 素材系统暂时独自成系统，不跟之前其他的空间混在一起：它的任务就是负责做素材。未来其他空间（试衣间、短剧、视频、游戏等）来用这里的素材；本系统可以复用当前其他空间的同类功能，只复用功能，不合并系统、不合并数据库。
4. 已验证的连线范式：巡查结果回流运营空间统计表（写今天行，不编数）；每日统计扩追踪任务（改任务表，不动历史记录）；一键发送带标记去重（三层去重：已发送/发送中/目标库标记查找，失败显示原因 + 可重试）。
5. 禁止的连线：第二个群发名额、定时发帖/互动、雷达用四来源以外的源。
6. 技术栈总览空间（slug ji-shu-zhan-zong-lan）就是全部技术栈的同步总览：任何 skill、连接器、工具、模型的增减与状态变化，都必须同步到它，写完就同步，不许拖、不许让它过期。同步责任在改动的人，不在任何自动机制。“它是手工快照”不是过期的理由。

## 验收

- 新连线写明：调哪个已有 action、回写哪个表/文件、不动哪些历史数据；无新增共享数据库；禁连的三项一项不沾。
