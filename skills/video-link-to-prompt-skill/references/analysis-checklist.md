# Video Analysis Checklist

## Access and evidence
- [ ] Can the actual video be played or inspected?
- [ ] Is audio available?
- [ ] Are captions/transcript available?
- [ ] Are the observations based on media, not just title/thumbnail?
- [ ] Are unknowns clearly marked?

## Creative idea
- [ ] One-sentence premise
- [ ] Opening hook
- [ ] Audience and intended emotional response
- [ ] Progression/escalation
- [ ] Payoff or ending image
- [ ] What is distinctive versus generic?

## Per-shot analysis
- [ ] Approximate timecode and duration
- [ ] Shot size: extreme wide / wide / medium / close-up / detail
- [ ] Angle: eye-level / low / high / overhead / POV / other
- [ ] Composition and subject placement
- [ ] Primary subject action, with start and end states
- [ ] Camera movement and direction
- [ ] Focus and depth-of-field impression
- [ ] Lighting direction, softness, contrast, exposure
- [ ] Dominant palette and color contrast
- [ ] Environment response and physical plausibility
- [ ] Sound, dialogue, foley, music, silence
- [ ] Cut/transition and continuity

## Transferable lessons
- [ ] Separate the core mechanism from incidental props/settings
- [ ] State what can be reused
- [ ] State what must change for the new concept
- [ ] Avoid assuming original prompt or technical camera settings
- [ ] Identify 2–4 high-value improvements

## Prompt quality
- [ ] One clear primary action per shot
- [ ] Avoid contradictory movement instructions
- [ ] Timeline fits total duration
- [ ] Consistent subject identity and wardrobe
- [ ] Coherent light and color
- [ ] Model settings separated from prompt text
- [ ] Placeholders are obvious and meaningful
