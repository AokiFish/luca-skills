# Image Reference → Prompt Skill

一个面向图像生成工作流的通用 Skill：上传参考图，分析构图、位置、遮挡、景深、视线、光线和色彩关系，最后输出可直接使用的生成提示词。

## 这个包实际做什么

- `SKILL.md`：核心工作流和质量标准。安装到具备视觉理解能力的 Agent 后，用户上传图片即可调用。
- `references/output-format.md`：推荐的结构化分析格式与输出检查表。
- `examples/example-analysis.md`：示例，展示“描述物体”如何升级为“描述物体之间的关系”。

## 安装与使用

1. 解压 ZIP。
2. 将 `image-reference-to-prompt` 文件夹放入你所用 Agent 的 skills 目录，或通过该 Agent 的 Skill 安装界面导入。
3. 在 Agent 中启用这个 Skill。
4. 上传一张参考图，输入例如：
   - `反推这张图的提示词，优先保证构图和饰品位置。`
   - `分析这张图，给我一版通用提示词和一版 Midjourney 版本。`
   - `这是生成结果，对照原图找出最大的三个偏差并修改提示词。`

不同 Agent 的 Skill 目录和导入方式不同；本包不声称所有平台都支持相同的安装方式。

## 重要的能力边界

这是一个**提示词工作流 Skill**，不是视觉模型本身。它不需要用户配置 API Key，也不调用脚本假装识图；它依赖宿主 Agent 能读取并理解用户上传的图像。如果宿主没有视觉能力，Skill 必须报告这一点，而不是编造图像细节。

不包含 Python 依赖、API 配置或运行时服务。核心功能就是 Skill 指令和示例，尽量降低安装摩擦。

### 与 video-link-to-prompt 配合
本 Skill 还能为视频分镜复用产出「角色卡」：当参考图要填进 video 模板的 `[主角N]` 占位符时，除图像提示词外，额外给出中英文自包含角色描述、禁用词/形体禁忌、一致性风险与表情/动作幅度边界。角色卡与分镜解耦，换角色不必重做分镜。详见 SKILL.md「为视频分镜复用：输出角色卡」。
