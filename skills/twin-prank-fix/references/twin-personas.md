# 双生人设系统（Twin Persona System）

两个角色不是「好坏对立」，是「对同一世界的两种读法」。把人设固定下来，后续每一拍的温差才有稳定来源。

## Twin A — 恶作剧 twin（抛出者 / Nezha-coded）

- **口是心非**：嘴上说不在乎 / 无辜，行动暴露真实意图（这里是「天真地搞破坏」）。坏事发生后一脸「不是我」地环顾四周。
- **话多一点**：哼歌、自言自语、无辜地东张西望。出声权在他手里。
- **职能**：抛出荒诞。是所有麻烦的源头，但观众不忍恨——因为他「没想那么多」，天真消解了恶意。
- **可选人格变体**（选一个固定，别混用）：
  - **哪吒式顽童**：嚣张但可爱，破坏带仪式感，做完还要摆个 pose。
  - **天然呆破坏王**：完全没意识到自己在捣乱，真诚地「帮倒忙」，越帮越乱。
  - **天真导演**：把世界当舞台，路人都是他的演员，自己只是「安排了一下」。

## Twin B — 善后 twin（接住者 / Silent Fixer）

- **零台词或只有语气词**（啧、叹气、翻白眼）。情绪靠停顿 + 眼神 + 微表情完成。
- **嘴上嫌弃、手上不停**：满脸嫌弃、翻白眼，但补救动作一秒没停——嫌弃与高效并存，这是他最迷人的反差。
- **职能**：用完全合理的反应接住荒诞，把世界恢复秩序。
- **可选人格变体**（选一个固定）：
  - **强势管教型**：像老妈子，边修边瞪，肢体语言在说「你给我等着」。
  - **冷面执行型**：面无表情，动作精准，反差最强——越冷静越搞笑。
  - **无奈共犯型**：明明可以走，却每次都留下收拾，自己都纳闷「我为什么又在捡」。

## 人设搭配原则

- **温差最大化**：A 越天真，B 越世故；A 越吵，B 越静；A 越动，B 越定。
- **不写对白脚本**（除非用户明确要）：用「动作 + 微表情 + 声音记号」描述，不写台词。例：「（无台词，翻白眼，顺手把歪掉的路障拨正）」。
- **两人必须同框同半径**：分开拍就失去接抛，G3/G6 同时失效。
- **长相交给参考图**：本系统只定人格与温差方向，不写五官身材；长相由 `image-reference-to-prompt` 类流程锁定的参考图负责，蓝图里只用 `[恶作剧T]` / `[善后T]` 占位符。
