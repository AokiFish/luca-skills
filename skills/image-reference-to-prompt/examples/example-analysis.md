# 示例：从“堆砌名词”变成“描述空间关系”

> 以下是演示分析方法的文字示例，不代表对用户当前图片的识别结果。

## 泛化且低效的写法

古风美女，华丽头饰，蓝色宝石，金色光线，电影感，高清，精致。

问题：没有说明人物在画面哪里、头饰离镜头多近、什么清楚什么模糊、光从哪边来。模型即使画出所有名词，也可能完全不像目标构图。

## 有空间约束的写法

一张紧凑的古风人像特写，人物面部占据画面右侧约三分之一，额头与下巴完整保留，脸部处于清晰焦平面。头部轻微转向画面左侧，但眼睛看向镜头附近。左侧近景有一组金色、珍珠与蓝色宝石组成的华丽发饰，贴近镜头并大幅虚化，形成遮挡式前景；少量蓝色晶石沿太阳穴分布。右后方的暖色春日逆光勾勒发丝和面部轮廓，背景柔和失焦。整体以暖金、珍珠白为主，蓝色宝石作为少量冷色点缀；皮肤保持真实细腻的纹理，金属、珍珠与晶石具有不同的反光特性。画面重点是右侧清晰面部与左侧虚化头饰之间的空间对比，不要把头饰全部放在人物头顶，也不要让前景饰品与脸部同样清晰。

## 为什么第二版更实用

- 把“头饰”从一个名词变成了“左侧近景、贴近镜头、遮挡、强虚化”的关系。
- 把头部方向与眼神方向拆开。
- 明确焦平面与逆光方向。
- 使用大致区域而非假装知道精确像素。
- 只排除会直接破坏构图的错误。
